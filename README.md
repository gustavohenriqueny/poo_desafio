# Desafio POO — iPhone

Desafio de projeto da DIO (2023): modelar as funcionalidades do iPhone com Programação Orientada a Objetos em Java.

O `Iphone` é composto por três aplicativos, cada um com seus próprios comportamentos:

- **Reprodutor musical:** listar, selecionar, tocar e pausar músicas
- **Aparelho telefônico:** listar contatos, ligar e atender
- **Navegador de internet:** abas, adicionar nova aba e atualizar página

Execute `src/main/java/Main.java`.

Projeto arquivado — mantido como registro de estudo.
